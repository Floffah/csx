# Security policy

Please report suspected vulnerabilities in CSX privately. Start with [Report a vulnerability](https://github.com/Floffah/csx/security/advisories/new) on GitHub. If private reporting is unavailable, open an issue asking the maintainers for a private security contact. Keep vulnerability details, proof-of-concept material, and sensitive data out of public issues and pull requests.

In your private report, include the affected CSX packages and versions, relevant build tool and runtime versions, steps to reproduce the issue, and the potential impact. Include a minimal example if possible, with any secrets and personal data removed.

Report ordinary bugs through the [issue tracker](https://github.com/Floffah/csx/issues/new/choose).
